Abstract

Recent advances in customized image generation exhibit strong capabilities in preserving global identity, yet they persistently struggle to synthesize consistent fine-grained details such as text and logos. To bridge this gap, we present FineForge, a unified dual-driven reinforcement learning framework designed to explicitly enhance high-frequency structural fidelity within a single denoising trajectory. First, we formulate an edge-aware terminal reward that provides an output-level, black-box learning signal for local detail accuracy. Second, to overcome the sparse reward dilemma inherent in standard RL, we introduce Advantage-Weighted Local Feature Alignment (AW-LFA). This white-box regularization module dynamically leverages the terminal reward as a gating mechanism to perform dense, patch-level feature distillation, directly aligning the model's internal hidden states with a pristine semantic space. Evaluated on customized generation benchmarks, FineForge demonstrates substantial improvements in text integrity, logo consistency, and structural sharpness, while preserving coherent global layouts.

Highlights

  • +33.8% relative OCR accuracy over the Flux.1 Kontext backbone (0.4400 → 0.5887), while keeping the same 8× VAE compression — the detail bottleneck is optimization, not the latent space.
  • Best on both Detailbench and DreamBench++, ahead of Gemini 3 Pro Image, Sora and Qwen-Image.
  • The advantage gate — not generic DINO distillation — is what makes local alignment work. Remove it and AW-LFA collapses back to the GRPO-only baseline.
  • Zero-shot transfer to non-product domains (signage, posters): +5.70 pp OCR accuracy.
  • Global quality is preserved: PickScore and Aesthetic Score move by less than 0.3%. No reward hacking of layout.

Method

FineForge closes a loop between an outcome signal and an internal signal. DIFT coarse-to-fine matching localizes each annotated detail region in the generated image; a Scharr edge pipeline strips away color and lighting so the reward measures structure only; GRPO turns that into a terminal, group-relative advantage. AW-LFA then reuses that same advantage as a ReLU gate: only rollouts that actually got the structure right are allowed to pull the DiT's hidden states toward a frozen DINOv3 feature space.

Reinforcement learning pipeline. Left: DIFT sliding-window + four-corner matching localizes the detail patch in the generated image. Middle: edge detection (grayscale → contrast enhancement → Gaussian denoise → Scharr operator → edge filtering). Right: GRPO computes group-relative advantages.

AW-LFA. The terminal advantage Âi passes through a ReLU gate, so only positive-advantage rollouts contribute the dense patch-level distillation loss. The teacher is a frozen DINOv3 ViT-B/16 fed an edge map; the student is the DiT's local hidden state at Block 36, projected through a trainable MLP.

Why edges: the teacher must describe the structural skeleton — strokes and logo boundaries — not surface texture and lighting, which the diffusion objective already supplies for free.

Dropping edge detection nudges DreamSim down, but the model then gets rewarded for repainting easy background area — OCR, PickScore and Aesthetic all fall. Edge detection keeps the reward pointed at high-frequency structure.

The advantage gate is the contribution

VariantDINOv2 ↑DreamSim ↓PickScore ↑Aesthetic ↑OCR ↑
GRPO only (no LFA)0.89250.11810.76635.08760.5647
+ Uniform LFA (no ReLU gate)0.89080.11490.77025.06420.5684
+ AW-LFA, RGB-patch teacher0.90470.10780.76145.04850.5802
Full AW-LFA (DINOv3, edge, gated)0.90160.10760.77315.16490.5887

Remove the ReLU gate and AW-LFA collapses back toward the GRPO-only baseline (OCR 0.5684 vs 0.5647) — ungated alignment lets conflicting gradients from low-reward rollouts cancel the good ones. Swap the edge teacher for an RGB patch and identity similarity edges up (DINOv2 0.9047) while OCR, PickScore and Aesthetic all drop: the model buys similarity by overfitting background appearance. The improvement is not "add DINOv3 distillation" — it is the gate.

Detailbench

3,900 product images at 1024×1024 sourced from Open Food Facts. Prompts generated with Qwen3-VL; annotators manually labelled 3–5 fine-grained detail regions (text and logos) per image with precise bounding boxes. Evaluation crops come from those human-annotated boxes, so the cropping step contributes zero variance.

We commit to fully open-sourcing the Detailbench dataset and all training / inference code upon acceptance.
